# 🚗 SuperRota
O SuperRota é uma aplicação web inspirada em apps de mobilidade urbana, desenvolvida com HTML, CSS e JavaScript.

O projeto permite:
-visualizar mapa interativo
-calcular corridas
-escolher tipo de veículo
-exibir distância, tempo estimado e preço
-simular busca de motorista
